# Слайдер изображений на JavaScript + jQuery (РГР по WEB-программированию, НГТУ)
Клиентское веб-приложение для просмотра набора изображений со сменой подписей и кнопками «Назад» / «Далее». Крайние кнопки блокируются на первом и последнем слайде.

## Запуск проекта
Нужно перейти в папку проекта. В ней:
- **запуск** - `make open`. Откроет `index.html` в браузере по умолчанию (через `xdg-open`)  
- **форматирование кода** - `make style`. Форматирует `*.html`, `*.css` и `*.js` через `prettier` (требуется установленный `prettier`)  

Сборка не нужна: проект - статическая страница, достаточно открыть `index.html` в любом современном браузере.

## О проекте

**Slider** - это фронтенд-приложение, выполненное как расчётно-графическая работа по дисциплине «WEB-программирование» (НГТУ, факультет АВТ, вариант 10).  
Цель работы - изучить клиентский язык JavaScript, объектную модель документа DOM и библиотеку jQuery.  

Приложение показывает набор из 8 изображений в окне фиксированного формата 9:16. Для каждого изображения отображается своя подпись, а переключение выполняется кнопками по бокам окна.

### Основные возможности

- Просмотр набора изображений с подписями
- Навигация кнопками «Назад» / «Вперёд»
- Блокировка кнопки «Назад» на первом изображении и «Вперёд» на последнем
- Окно просмотра с постоянным соотношением сторон 9:16, изображение вписывается без искажений (`object-fit: contain`)
- Адаптивный дизайн: масштабирование через `min(75vh, 90vw)`, медиа-запросы для телефонов и альбомной ориентации
- Подпись с полупрозрачной подложкой и размытием фона (`backdrop-filter`)
- Пользовательский шрифт Geologica через `@font-face`

## Как это работает

- Все слайды описаны массивом объектов `slides` с полями `src` и `caption`. Чтобы добавить изображение, достаточно добавить элемент в массив.
- Текущая позиция хранится в переменной `index`.
- Функция `showSlide(i)` обновляет `src` и `alt` изображения, текст подписи и состояние кнопок (`disabled`).
- Обработчики кнопок подключены через `.on("click", ...)` и проверяют границы массива, поэтому выйти за пределы набора нельзя.
- Первый слайд показывается при загрузке страницы в `$(document).ready()`.
